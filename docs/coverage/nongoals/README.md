# Per-service non-goals (hand-maintained)

The capability coverage pages under `docs/coverage/` are generated by
`go generate ./...` and **must not be edited by hand** — except here.

Drop a `<service>.md` fragment in this directory (matching a service name from
the coverage index, e.g. `storage.md`) and the generator inlines it under that
service's **"Not in scope"** heading. Fragments are never overwritten, so this
is where human judgement about what a service deliberately does *not* emulate
lives.

Example — `storage.md`:

```markdown
- Server-side object encryption is stored but not enforced on read.
- Cross-region replication is not simulated.
```

A service with no fragment shows a default "not documented yet" line.
